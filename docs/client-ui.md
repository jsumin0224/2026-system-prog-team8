
# Client UI & Termios (담당자 A - 이재열)

## 1. 담당 업무
터미널 제어 기반 ATM 클라이언트 인터페이스 구현

## 2. 주요 구현 기능

### 2-1. 터미널 입력 제어
- termios를 활용한 터미널 입력 모드 제어
- stty -icanon 설정을 활용한 엔터 키 없는 메뉴 선택
- 사용자 입력에 따른 ATM 메뉴 즉시 실행

### 2-2. 비밀번호 입력 보안
- stty -echo 또는 termios 설정을 활용한 입력 에코 제어
- 비밀번호 입력 시 화면에 문자가 노출되지 않도록 구현
- 비밀번호 입력 완료 후 터미널 설정 복구

### 2-3. ATM 클라이언트 UI
- ATM 초기 화면 및 메뉴 구성
- 입금, 출금, 계좌이체, 잔액조회 메뉴 구현
- 사용자 입력에 따른 화면 전환
- 잘못된 입력에 대한 예외 처리

## 3. 담당 파일 및 모듈
- client.c : ATM 클라이언트 메인 코드
- terminal.c : 터미널 입력 및 출력 제어
- terminal.h : 터미널 관련 함수 선언

## 4. 다른 담당자와의 연동
- 담당자 B와 거래 요청 및 응답 데이터 전달 방식 협의
- 담당자 B가 정의한 통신 프로토콜에 맞춰 거래 데이터 전송
- 서버로부터 전달받은 처리 결과를 화면에 출력
