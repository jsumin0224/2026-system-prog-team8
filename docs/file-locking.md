
# File Locking & Database (담당자 C - 전수민)

## 1. 담당 업무
파일 잠금 및 데이터 무결성 보장을 위한 계좌 데이터 관리 구현

## 2. 주요 구현 기능

### 2-1. 파일 잠금 구현
- fcntl()을 활용한 파일 잠금 기능 구현
- 계좌 데이터 파일의 동시 접근 제어
- 여러 ATM 프로세스에서 동일 계좌 접근 시 데이터 충돌 방지
- 출금 및 입금 처리 중 데이터 무결성 유지

### 2-2. 계좌 데이터 관리
- 계좌 정보 파일 생성 및 관리
- 계좌번호와 비밀번호 관리
- 계좌 잔액 조회 및 수정
- 입금 및 출금에 따른 잔액 변경
- 계좌이체 시 송금 및 수신 계좌 데이터 처리

### 2-3. 거래 내역 관리
- 거래 내역 파일 기록
- 거래 유형 및 거래 금액 저장
- 거래 일시 및 계좌 정보 기록
- 거래 처리 결과 관리

### 2-4. 데이터 안정성
- 파일 입출력 오류 처리
- 계좌 정보 변경 시 동기화 처리
- 동시 거래 상황에서 데이터 손실 방지

## 3. 담당 파일 및 모듈
- account.c : 계좌 정보 조회 및 수정
- account.h : 계좌 관련 함수 선언
- file_lock.c : 파일 잠금 및 동기화
- transaction.c : 거래 내역 관리

## 4. 다른 담당자와의 연동
- 담당자 B의 서버 프로세스에서 호출할 계좌 처리 함수 제공
- 담당자 A가 요청한 거래의 처리 결과 데이터 제공
- 담당자 D의 관리자 모니터링을 위한 거래 로그 파일 제공
