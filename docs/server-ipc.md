
# Server & IPC (담당자 B - 냠게렐)

## 1. 담당 업무
멀티프로세스 기반 ATM 서버 및 IPC 통신 구조 구현

## 2. 주요 구현 기능

### 2-1. 서버 프로세스 관리
- fork()를 이용한 자식 프로세스 생성
- 중앙 은행 서버 역할의 부모 프로세스 구현
- ATM 클라이언트 역할의 자식 프로세스 관리
- 여러 ATM 프로세스의 동시 실행 및 관리

### 2-2. IPC 통신 구현
- pipe()를 활용한 프로세스 간 통신 구현
- ATM 프로세스에서 서버로 거래 요청 전달
- 서버에서 거래 결과를 클라이언트로 전달
- 부모 및 자식 프로세스 간 데이터 송수신 처리

### 2-3. 통신 프로토콜 설계
- 거래 요청 데이터 구조 정의
- 거래 유형별 데이터 구분
  - 입금
  - 출금
  - 계좌이체
  - 잔액조회
- 서버 응답 데이터 구조 정의
- 통신 오류 및 데이터 수신 예외 처리

## 3. 담당 파일 및 모듈
- server.c : 중앙 서버 및 프로세스 관리
- ipc.c : IPC 통신 구현
- ipc.h : IPC 관련 함수 및 데이터 구조 선언

## 4. 다른 담당자와의 연동
- 담당자 A와 클라이언트-서버 통신 규격 협의
- 담당자 C의 계좌 데이터 처리 함수와 연동
- 담당자 D의 시그널 및 프로세스 종료 처리와 연동
