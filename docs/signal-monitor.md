
# Signal & Monitoring (담당자 D - 이지우)

## 1. 담당 업무
시그널 기반 예외 처리, 자동 로그아웃 타이머 및 관리자 모니터링 시스템 구현

## 2. 주요 구현 기능

### 2-1. 시그널 처리
- signal() 또는 sigaction()을 활용한 시그널 처리
- SIGINT(Ctrl+C) 입력에 따른 안전한 종료 처리
- 프로세스 종료 시 파일 디스크립터 정리
- 메모리 및 시스템 자원 정리

### 2-2. 자동 로그아웃 타이머
- alarm() 및 SIGALRM을 활용한 시간 제한 기능 구현
- 일정 시간(예: 30초) 동안 입력이 없을 경우 자동 로그아웃
- 타이머 종료 시 초기 ATM 화면으로 복귀
- 거래 진행 상태에 따른 타이머 관리

### 2-3. 관리자 모니터링 시스템
- 관리자 전용 모니터링 화면 구현
- 현재 실행 중인 ATM 프로세스 상태 확인
- who 명령어 등을 활용한 접속 사용자 정보 확인
- stat()을 활용한 거래 로그 파일 정보 확인
- 거래 로그 파일 크기 및 수정 시간 모니터링

### 2-4. 관리자 TUI 구성
- ATM 프로세스 실행 상태 표시
- 거래 로그 파일 정보 표시
- 실시간 시스템 상태 확인
- 관리자 화면 갱신 기능 구현

## 3. 담당 파일 및 모듈
- signal_handler.c : 시그널 처리
- timer.c : 자동 로그아웃 타이머
- monitor.c : 시스템 모니터링
- admin.c : 관리자 모드 및 TUI

## 4. 다른 담당자와의 연동
- 담당자 A와 자동 로그아웃 및 터미널 복구 기능 연동
- 담당자 B와 프로세스 종료 및 시그널 처리 연동
- 담당자 C와 거래 로그 파일 및 계좌 데이터 모니터링 연동
